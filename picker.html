Where ChatGPT images are saved

Workaround — takes 20 seconds, works the same in the end:

  1. Open your browser's Settings → Downloads and set Location to the folder you want (e.g. /home/ajay/Pictures/monke).
  2. Leave "Ask where to save each file" off.
  3. Set the subfolder below. Images land in Downloads/ChatGPT.

Leave it empty to save straight into the download location with no subfolder.
